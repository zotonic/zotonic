# Working on Zotonic

Zotonic is an Erlang umbrella application. Write concise, documented code using
pattern matching and functional Erlang. Use plain JavaScript and Zotonic's
template_compiler syntax for templates.

- Read [zotonic-coding](.agents/skills/zotonic-coding/SKILL.md) for coding tasks.
- Apply [zotonic-security](.agents/skills/zotonic-security/SKILL.md) when implementing or reviewing changes.
- Select other skills in `.agents/skills/` by their descriptions and read those
  relevant to the task. Use `zotonic-development-tools` to inspect running sites.

`.agents/skills/` is the canonical source. `.claude/skills/` contains discovery
symlinks; maintain skills in the canonical directory. See
[the shared skills guide](.agents/README.md) when adding a skill.
