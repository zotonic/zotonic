# Documentation images

`scomp-base-debug-expanded.png` illustrates expanded template variables in the
`debug` scomp documentation. Its Markdown path is relative to the Erlang source
file in `src/scomps`, so it starts with `../../priv/doc/`.

The zotonicwww2 reference importer reads the image from the source checkout and
imports it as a named media resource. Keep the source image here; do not add a
second copy to the website's static library.
