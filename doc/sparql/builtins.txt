SPARQL built-in status
=======================

The scanner and parser recognize the SPARQL 1.1 built-in names below. The SQL
generator supports only the functions marked supported or partial. See
builtins-mapping.txt for the PostgreSQL expressions and compatibility notes.


Supported scalar functions
--------------------------

    BOUND
    RAND
    ABS
    CEIL
    FLOOR
    ROUND
    CONCAT
    SUBSTR
    STRLEN
    UCASE
    LCASE
    CONTAINS
    STRSTARTS
    STRENDS
    STRBEFORE
    STRAFTER
    YEAR
    MONTH
    DAY
    HOURS
    MINUTES
    SECONDS
    NOW
    UUID
    STRUUID
    MD5
    COALESCE
    IF

Supported with differences from complete SPARQL RDF semantics:

    REPLACE
    REGEX
    isLITERAL
    isNUMERIC
    isIRI
    isURI
    isBLANK
    sameTerm
    IRI
    URI

The regex functions use the common subset of XPath and PostgreSQL POSIX regular
expressions. The RDF term tests use the available SQL and JSONB types as an
approximation because complete RDF term metadata is not stored in expressions.
`isURI` is an alias of `isIRI`. `isBLANK` is false for Zotonic values because
blank nodes are not represented as SQL values.

IRI and URI constructors resolve constant strings against the query BASE and
leave existing IRI expressions unchanged. Dynamic text expressions pass
through as IRI text; dynamic relative values are not resolved against BASE.


Supported aggregates
--------------------

    COUNT, including COUNT(DISTINCT *)
    SUM
    MIN
    MAX
    AVG
    GROUP_CONCAT, including SEPARATOR
    SAMPLE on PostgreSQL 16 and newer

GROUP BY, HAVING and aggregate expressions in SELECT and ORDER BY are supported.
SAMPLE uses PostgreSQL any_value() and returns an error on older versions.


Supported XSD constructor functions
-----------------------------------

Expanded datatype IRIs are handled as function calls for:

    xsd:string
    xsd:boolean
    xsd:integer
    xsd:long
    xsd:int
    xsd:short
    xsd:decimal
    xsd:float
    xsd:double
    xsd:dateTime
    xsd:dateTimeStamp


Recognized but unsupported
--------------------------

    STR
    LANG
    LANGMATCHES
    DATATYPE
    BNODE
    ENCODE_FOR_URI
    TIMEZONE
    TZ
    SHA1
    SHA256
    SHA384
    SHA512
    STRLANG
    STRDT

EXISTS and NOT EXISTS graph-pattern filters are also unsupported. The scanner
recognizes the keywords, but the parser does not build these expression nodes.

URI is defined by SPARQL as a synonym for IRI; it is not an obsolete grammar
entry.
