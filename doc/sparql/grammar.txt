W3C SPARQL 1.1 documentation

https://www.w3.org/TR/sparql11-query/

Grammar in EBNF:

https://www.w3.org/TR/sparql11-query/#grammar

This grammar has been adapated to a LALR grammar, compatible with Yecc.
See sparqlz_parser.yrl


LALR/Bison-based SPARQL parsers:

* Rasqal: SPARQL requires Bison 3.0,” which can generate LALR parsers.
* RDFLib's old parser: listed by W3C as "BisonGen-based"
* Elixir sparql - but seems incomplete when compared to the EBNF (https://github.com/langens-jonathan/sparql)

So: there is no canonical W3C LALR grammar, but there are some examples.
