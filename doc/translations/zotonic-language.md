# Zotonic language-name translation context

This catalog supplies language names for Zotonic's language selection and translation-management interfaces. Readers include website visitors, content editors, translators, and administrators.

- Use the established name of each language in the target locale. These are localized display names; do not automatically substitute each language's self-name unless individual context explicitly requires it.
- Preserve distinctions between languages, regional varieties, and scripts where the source identifies them. Do not collapse Simplified and Traditional Chinese or distinct regional variants into one generic label.
- Use standalone selector labels with natural target-language capitalization and spelling. Do not add explanations or forms of address.
- Follow relevant entries in Zotonic's Crowdin glossary. Preserve language codes and placeholders exactly; translate displayed names, not identifiers.
- Use the target locale's script and regional vocabulary. For RTL languages, write natural text without manually reversing names or embedded language codes.
- Flag an unclear language or variant for review rather than guessing its identity.

This is a naming catalog, so formal/informal address and action-button conventions do not apply.
