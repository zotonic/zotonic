# Zotonic country-name translation context

This catalog supplies country and territory names for Zotonic's web interface, including address forms and country selectors. Readers include website visitors, content editors, and administrators.

- Use established names in the target language for the country or territory identified by the source. Preserve distinctions between entries; do not replace a specific territory with a broader country or region.
- Translate names as standalone selector labels, with the target language's normal capitalization and spelling. Do not add explanatory sentences, articles required only in running prose, or forms of address.
- Preserve source qualifiers needed to identify an entry. Flag an unclear or outdated source name for review rather than silently changing the geographic entity.
- Follow relevant entries in Zotonic's Crowdin glossary. Preserve any codes or placeholders exactly; translate the displayed name, not the underlying identifier.
- Use the target locale's script and regional vocabulary. For RTL languages, write natural text without manually reversing names or codes.

This is a naming catalog, so formal/informal address and action-button conventions do not apply.
